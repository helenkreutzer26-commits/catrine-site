# Проект «Сайт Тест» — CATRINE

## Что в папке
- `сайт CATRINE/index.html` + `img/` — сайт (открывать index.html в браузере)
- `catrine-github/` — та же версия сайта, все файлы в одной папке (для GitHub / Vercel)
- `CJM_кухня_на_заказ.html` — карта пути клиента, персона и 3 боли, структура сайта
- `CATRINE_каталог_финал.pdf`, `цветовая палитра*.jpg`, `шрифты и визуал.jpg` — исходники

## Карточка клиента
**Айгерим, 34 года.** Новостройка, 3 комн., 78 м². Муж и двое детей.
Запрос: кухня + шкаф в прихожую. Бюджет «до 2 млн», реально до 2,5 млн ₸.
Выбирает она, деньги одобряет муж.

1. **Сроки.** Платит аренду и ипотеку одновременно, каждый месяц задержки стоит денег. Хочет въехать к Новому году.
2. **Недоверие.** Прошлый частник сделал кухню, фасады у мойки вздулись, мастер пропал.
3. **Защитить выбор.** Муж считает, что можно дешевле. Нужны аргументы для разговора дома.

## ИИ-Консультант (OpenAI API)
На сайте интегрирован онлайн-консультант на базе официального OpenAI API (`gpt-4o-mini`).
- Сервер: `server.js` (эндпоинт `POST /api/chat`)
- Настройки API: файл `.env` (`OPENAI_API_KEY=ваш_ключ_openai`)
- Виджет: `chat.css` и `chat.js`
